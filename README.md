# DC Hub — Claude Code plugin

The real-time agentic procurement endpoint and data center knowledge hub.

Connects Claude Code to the DC Hub remote MCP server at https://dchub.cloud/mcp for live data center market, power/grid, energy and fiber intelligence for site selection. The free tier needs no key.

Install: `/plugin marketplace add azmartone67/dchub-claude-plugin`, or add `.mcp.json` to your project.

- Server source: https://github.com/azmartone67/dchub-mcp-server
